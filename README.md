# Life OS Frontend Prototype

Life OS의 첫 사용자 흐름과 연령 적응형 UI를 검증하기 위한 프론트엔드 프로토타입입니다.

## 현재 포함된 화면과 동작

- 오늘의 브리핑과 할 일 완료 체크
- 기록, 기억, AI 대화 메뉴 전환
- 기록 추가 메뉴
- 통화 파일 선택 및 형식·25MB 크기 검사
- 통화 제목, 참여자 수, 본인 참여 여부, 녹음 날짜 입력
- 개인정보 확인 전 분석 시작 버튼 잠금
- 업로드 및 처리 단계 시뮬레이션
- 10대, 20~39세, 40~59세, 60세 이상 보기 전환
- 모바일 하단 메뉴와 데스크톱 사이드 메뉴

현재는 UI와 사용자 흐름 검증 단계이므로 로그인, 실제 파일 저장, 음성 변환, AI 분석 서버는 연결하지 않았습니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

코드 검사와 빌드:

```bash
npm run lint
npm run build
```
